## 1. 一般 6j 的 Biedenharn–Elliott 遞歸（T84–T87 / A68–A70）

### 1.1 數學抽象

Wigner 6j 係數 `{a b c; d e f}` 是三個角動量的重耦合（recoupling）係數：
兩種耦合次序 `(a b) c` 與 `a (b c)` 之間的幺正變換。兩個經典恆等式：

* **Biedenharn–Elliott**（結合律 / pentagon 的 s-變體）：
  `Σ_X (−1)^{R+X}(2X+1){abX;cdp}{cdX;efq}{efX;bar} = {pq r;ead}{pqr;fbc}`，
  即「先 (ab) 再 (cd) 再 (ef)」與「先 (pq) 再 …」兩條重耦合路徑相等——
  這是散射振幅可結合性的 Selection Rule，也是 F-矩陣五邊形關係的對偶形式。
* **Racah 正交性**（單位性）：`Σ_X (2X+1){abX;cde}{abX;cde'} = δ_{ee'}/(2e+1)`——
  重耦合矩陣的行正交。

第七輪的 F 矩陣（T75–T77）只證了 `(½)⁴` 一族；本輪是一般 `6j` 的閉式與上述兩恆等式。

### 1.2 計算機抽象

* **加倍標籤（doubled labels）**：`Int32 k` 表示自旋 `k/2`。三角條件
  `|a−b| ≤ c ≤ a+b ∧ a+b+c ≡ 0 (mod 2)` 完全落在整數上，沒有半整數捨入；
  三項和 `a+b+c` 為偶數時 `(a+b+c)/2` 為整數，Racah 求和的 `Z` 步長 2、
  相位 `(−1)^{Z/2}` 都是整數運算。
* **A68 `sixj`（Racah 閉式）**：前置 `Δ` 三角因子 × `Z ∈ [zmin, zmax]` 的有限和，
  階乘以 `dfact` 計算（f64 下 `n ≤ 18` 精確，本輪加倍標籤 ≤ 8 → `17!`）。
  無外乘相位：sympy `wigner_6j = (−1)^{j1+j2+j4+j5}·racah(...)` 的兩個相位恰好相消，
  故閉式與 `wigner_6j` 逐位同式。
* **A69 `be_defect` / A70 `ortho_defect`**：把求和寫成顯式殘差函數，
  適用前提（triad 篩選、X 範圍非空）由 `be_applicable` / `ortho_applicable` 判定——
  前提之外不作任何斷言（數學上恆等式本來就要求這些前提）。

### 1.3 定理與證書

| 定理 | 命題 | 證書 |
|---|---|---|
| T84 | 已知閉式值 + 不合格 triad ⇒ 0 | `{111;111}=1/6`、`{½½1;½½1}=1/6`、`{111;110}=−1/3`、`{½½0;½½0}=−1/2`、`{110;110}=1/3`、`{000;½½½}=−1/√2`；`(½)⁴` 與 `1>0+0` 型不合格 ⇒ 0 |
| T85 | 6j 在 24 個四面體對稱下不變 | 4⁶ 網格 × 24 置換 = 98,304 次比較，逐對 ≤ 1e-12；24 元清單由全相異配置的不變置換交集生成 |
| T86 | Biedenharn–Elliott 求和規則 | 5⁹ = 1,953,124 配置篩出 **11,448** 個前提合格者，worst \|defect\| = **1.67e-16**（< 1e-9） |
| T87 | Racah 正交關係 | 5⁶ 篩出 **590** 個（triad + 非空 X 範圍），worst \|defect\| = **4.44e-16**（< 1e-9） |

外部交叉驗證（Python 沙盒，`sympy 1.14.0`，不在 repo 測試內）：
`sixj` vs `sympy.physics.wigner.wigner_6j` 在 5⁶ 網格 **max \|err\| = 1.11e-16**。

### 1.4 誠實邊界

* 階乘用 `Double`：`n ≤ 18` 精確；更大標籤會引入捨入（本輪上限加倍 8 = 自旋 4）。
* 殘差判定用 `1e-9` 容差（浮點求和誤差 ~1e-16 量級，留 7 個數量級餘量）。
* BE 求和中宇稱為奇的項（`R+X` 為奇）**經驗上恆為 0**（Python 驗證 8,098 項全零），
  實作只在 `R+X` 為偶時累加——這是計算觀察，不是證明；若將來出現反例，
  T86 會先紅。
* 與 sympy 的逐位比對只在沙盒跑過；repo 內的憑證是 T84 已知值 + T85–T87 代數恆等式
  （恆等式本身不依賴 sympy）。

## 2. |V(−1)| 行列式定律的視窗伸縮（T88–T91 / A71–A72）

### 2.1 數學抽象

`T(2,n)` 環面結的瓊斯多項式滿足**行列式律** `|V(−1)| = det = n`（奇數 `n` 為結）。
Kauffman 計算把 `⟨β̂⟩` 存成 `A` 的多項式，正規化 `(−A³)^{−w}` 把指數推到
`−3n` 量級——**視窗必須隨 `n` 線性增長**，否則 `lz_mul` 靜默丟項，
`V(1)/V(−1)` 離開行等式而 lattice defect 仍為 0（截斷對 lattice 檢測隱形）。
行等式本身（用它自己）就是視窗不足的檢測器。

### 2.2 計算機抽象

* **A71 `Lz2` + `jones_t2_scaled`**：與模組 34 的 `Lz` 同構、但視窗 `off` 由呼叫者給出；
  `lz2_mul` 返回**丟項計數**（模組 34 靜默）。TL_2 乘法規則（由 `tl_compose` 驗證：
  `e·e → e` 且帶 1 圈）：`(c0,c1)·(d0,d1) = (c0d0, c0d1 + c1d0 + δ·c1d1)`。
* **A72 `t2_window_bound(n) = 6n−2`（視窗伸縮律）**：解析跨度
  `spanA = (−3n+2, n+2)`、`spanN = (−6n+2, −2n+2)`（T88 逐 `n` 驗證），
  `−6n+2 = −bound` 恰落在下界 ⇒ **bound 之下零丟項**。
  係數增長是 `O(n)`（`c0 = A^n`；`c1_{n+1} = A^{n−1} − A^{-3}·c1_n`，每步只增一項）
  ——這是 `Int32` 安全的解析理由（不是經驗）。
* **邊界情形 `n = 1`**：`δ·c0` 的 `−1` 冪與 `c1` 抵消，`spanA = (3,3)`、`spanN = (0,0)`
  （公式對 `n ≥ 2` 成立）——T88 單獨釘死，不混進通式迴圈。

### 2.3 定理與證書

| 定理 | 命題 | 證書 |
|---|---|---|
| T88 | bound 之下零丟項 + 解析跨度 | `n = 2..41`：`spanA`/`spanN` 逐點等於 `−3n+2` 等公式、`drops = 0`；`n=1` 邊界單獨驗 |
| T89 | 行等式定律 + 緊界 | 奇數 `n = 3..61`：`V(1) = 1`、`\|V(−1)\| = n`、defect 0、drops 0；`off = bound−1` 恰丟一項 ⇒ `V(1) = 2`、`\|V(−1)\| = n−1`（`n = 17,19,21`） |
| T90 | 固定 ±96 視窗的**靜默**壞值 | 模組 34 `jones_polynomial`：`n=17 → (V1, V−1) = (2, 16)`、`19 → (1, −15)`、`21 → (2, 14)`、`25 → (2, 12)`、`31 → (1, −9)`，**defect 全為 0** |
| T91 | 三路交叉驗證 | `n ≤ 15`：scaled 與模組 34 逐項相等；`k = 8,9,10,12,15`（`n = 17..31`）：scaled 與 `lz_mirror_t(jones_torus2_skein(k))` 逐項相等，skein 自身滿足行等式 |

無視窗的 Python 神諭（同一條乘法規則，字典精確）獨立驗證 `n = 1..61`：
跨度公式零失配、行等式全過——與 MoonBit 測試互為印證。
真值 `(V(1), V(−1))`：`n=17 → (1, 17)`、`19 → (1, −19)`、`21 → (1, 21)`、`25 → (1, 25)`、`31 → (1, −31)`。

### 2.4 誠實邊界

* **B₄ 仍然未來**：本輪只做 `TL_2`（`B_2`）的視窗伸縮；`TL_4` 有 14 個基元素、
  `B_4` 要 4 個生成元，視窗律要重新推導（`OCTAVE.md` §1.4 的待辦只解決了 `B_2` 半邊）。
* **偶數 `n` 是連結**：`V` 出現在 `t^{1/2}` 幂上，lattice defect > 0 屬預期，
  不在本輪定律範圍（T88 的跨度律對偶數同樣成立，因為它在 `lz_to_t` 之前）。
* **skein 路徑也有自己的視窗**：`Hlz` 走 `t` 半冪、`±96 ⇒ t ∈ [−48, 47]`，
  對 `n ≤ 31` 的真值 `t`-跨度 `(−46, −15)` 夠用、`k ≥ 16`（`n = 33`）起會壞——
  T91 只測到 `k = 15`，不是「skein 永遠對」。
* T90 的壞值是**實測釘死**（模組 34 行為），不是推導值；它們同時證明
  「兩條模組 34 路徑在 `n = 17` 仍互相一致地錯」——一致性 ≠ 真值。

## 3. 跨詞表 L3 對齊融合（T92–T94 / A73）

### 3.1 數學抽象

同詞表融合（`src/39`，T81–T83）的候選 id 逐位對應；跨詞表（R1 151,643 vs
Qwen2.5-Coder 51,412 等）id 空間不同，必須先**對齊**再融合：
共享 token 凸組合、單側 token 用「前綴相容」兜底（byte 級 LCP 的抽象：
`a` 與 `b` 任一方為對方前綴 ⇔ 兩段 byte 序列在較短者內逐位相等），
無相容候選時退到 `min(對側) − margin` 的 floor —— **不再硬否決**
（對比 T81：`fuse_product` 對任一成員的 0 是交集語義的硬否決；
跨詞表下「另一邊根本沒有這個 token」不是證偽，floor 才是正確語義）。

### 3.2 計算機抽象

* token 以 `String` 表示（ASCII 測試詞表）；定律與表示無關，
  真實 tokenizer 的非 UTF-8 位元組 token 可原樣換成 `Bytes`（記錄在案的邊界）。
* **A73 `align_scores`（raw）/ `align_fuse`（= `fuse_log_softmax`）**：
  `α` 永遠配 left 自有項——這是 swap 反變的前提；
  輸出序 = left 序在前、right 獨有在後（同詞表情形與 `fuse_product` 逐位對應）。
* 兜底 `align_fallback`：前綴相容候選的最大 logprob；一個都沒有 ⇒ `min − margin`。

### 3.3 定理與證書

| 定理 | 命題 | 證書 |
|---|---|---|
| T92 | 同詞表歸約 | `align_fuse(L,L,α)` 與 `fuse_product([row,row],[α,1−α])` **逐位 ≤ 1e-15**（同浮點運算次序：own 在前、對側在後，與 `fuse_raw_product` 同序） |
| T93 | swap 反變 | `(L,R,α) ↔ (R,L,1−α)` 逐 token：raw 在 `α=0.5` **精確相等**（own-weight 恆配自有項、加法可交換）、`α=0.3` ≤ 1e-12（`1−(1−α) ≠ α` 的 ulp）；normalized ≤ 1e-12（logsumexp 輸出序不同） |
| T94 | 兜底 / floor / 無否決 | 不相容詞表雙側保留且有限（`fuse_product` 同輸入會全 `−∞`）；`"the"` 前綴兜底 `= 0.5·(−0.1) + 0.5·max(−0.5,−0.2) = −0.15`；floor `= min − margin` 精確值 `−0.6` |

### 3.4 誠實邊界

* 測試用**合成 ASCII 候選表**：repo 內沒有 tokenizer JSON（`scripts/hexad/data/` 只有
  `agents.json`）。真實跨詞表重疊的量級見
  [`HEXAD_VOCAB_OVERLAP.txt`](HEXAD_VOCAB_OVERLAP.txt)（K2∩R1 42,986、
  K2∩Qwen3.5 50,932、R1∩Qwen3.5 131,586、R1∩Limite id 全同 151,643）；
  逐模型對合併可行性見 `HEXAD_6IN1_PLAN.md` §15。
* 沒有 GPU / 權重：本輪不執行任何真實合併或前向——對齊律是純資料流定律，
  在合成表上證完即止。
* `String` 前綴 vs 原始位元組：真實 byte token 的前綴判定要 `Bytes` 版本；
  兩者在 ASCII 上逐位相同，非 UTF-8 上未驗（邊界如上）。
