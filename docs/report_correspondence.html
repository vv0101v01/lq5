§1 模疊上的完備化 D-模：Hasse 對 T49–T52

形式圓盤上的完備化 D-模 = Hasse 對 (F, W)；mod p 殘餘上正規化為 F = x^p、W = f ↦ f(x^(1/p)) 的係數抽取。三條可判定定律全部以整數矩陣秩鎖定：

  • T49 W ∘ F = id（在可表示窗口上逐係數）
  • T50 ker(W − 1) = k（秩 depth − 1，整格 p ∈ (2, 3, 5, 7)）
  • T52 特徵 p 的 de Rham 側 ker d = k[x^p]（矩陣秩 = ⌈depth/p⌉ 兩路互證）
  • ¬T53 多項式載體 Z/p[x]/(x^p) 無法承載：冪零 x 被結構映射消滅 ⇒ 凝聚層必須完備化為 D-模

§2 ind-凝聚層：濾過歸納極限 T55 / ¬T56

凝聚層的 ind-完備化抽象成「階梯 + 轉移」表 IndSheaf{term, limits}。 雙極限交互定理在穩定塔上成立（缺陷 0），而含懸掛轉移 [2] 的塔上 R⁰∘lim 與 lim∘R⁰ 相差 4 個度數單位——這正是 ¬T56 的反例見證， 與 T55 一起把「何時可以交換」變成可判定的有限檢查。

§3 阿貝爾伽羅瓦上同調 + 科特維茨雙重性 T53 / T54 / T57a

T53：Hom(Z_ℓ^×, Q_ℓ^×) 的 U^n-類恰為 ℓ−1 個，與層級 n 無關 （Serre 正規化 a ↦ a·u^(ℓ−1) 的軌道窮舉）。T54：ℓ 進圓盤上的截斷 Lubin–Tate 作用 γ·(δ·x) = (γδ)·x 在 2 階截斷下仍結合（A43）。 科特維茨符號的法則（本輪的可證版本）： ε_g1·ε_g2 = −1、ε_s1·ε_s2 = (−1)^d、ε_g1·ε_s2 = (−1)^{d+1}， 在 d ∈ [1..6] × θ ∈ {0,1} 全網格缺陷 0。

§4 一般線性群的數值局部朗蘭茲 + 佐武參數 T57–T60

Hecke 特徵值 由 η-積導出（五邊形數展開的卷積，A46；`eta11_hecke_coefficients`）， 再與點計數互證：a_p = p + 1 − #E(F_p) 在全部 p ≤ 59 上缺陷 0。 Satake 參數 {r₁, r₂} 滿足 r₁+r₂ = a_p、r₁r₂ = p（T57b）； Jacquet–Langlands 側用帶符號複數 Newton 恆等式 e₂ = (p₁²−p₂)/2 = p 鎖定（T59）； GL₂ 重耦 ch(std)² = ch(sym²) + ch(∧²)、GL₃ 成對律與幾何 Satake P_IC(Gr_ω₁)(1) = dim V_ω₁（T58）；Fricke 特徵值 +1（T60）。

§5 哈密頓群空間 × 哈密頓對偶 × S-對偶字典 T61–T63

一個 Jacobi 三對角矩陣，三種讀法：離散哈密頓量、正交多項式三項遞推、Hamburger 矩=譜測度。 Favard 判據 p_N = charpoly(J_N) 以「p_N 在 sym_eigenvalues 譜上為 0 且譜互異」鎖定； 矩 Hankel 矩陣正定（Hamburger 可解性）。哈密頓對偶群空間：秩 1 情形即 (p+1)-正則樹， 雙陪集球 |S_n| = (p+1)p^(n−1)、閉測地線偶長度、樹球 = 子群指標增長。 S-對偶：算子 S: (G, κ, q, λ) ↦ (G^∨, κ∨, 1/q, 1/λ) 是對合， 度量對偶 κ·κ∨ = 1，Wilson–'t Hooft 交換相位複共軛、群空間求逆與 S 交換。

§6 譜 zeta 的 Hadamard 馴化 × Montgomery 對 × Clausen 節點 T65–T68

T65：Λ(s) = Λ(1−s)、臨界線實值、Schwarz 反射——三條一起鎖死完成 L-函數的馴性； T66：Montgomery 平均間距 2π/log(T/2π) 與三零點的實測間距比； T67：極點 / 阿基米德 Γ / Dirichlet 三因子重組 ↔ Hadamard 乘積截面（每對共軛零點貢獻 1+((s−½)/γ)²，單調遞增有界 ⇒ 屬 1 絕對收斂）； T68：Bloch–Wigner 節點 Cl₂(π/2)=Catalan、Cl₂(π/3)=1.01494…、 Cl₂(2π/3)=0.67662…，階梯恆等式 Cl₂(2π/3) = (2/3)·Cl₂(π/3)（誤差 < 1e-6，8 000 項傅立葉和）。

§7 高階範疇中的拉回、前推與伴隨 T64 / A50

六函子模型：f^! = f^*[2d](d)、f_! = [−2d](−d)（光滑），Verdier 對偶把 f^! 換成 f_!（方向相反），因此 f_!∘D ≃ D∘f^! 的缺陷在偶相對維數上恆 0； Beck–Chevalley 在 span 上等價於 d_right − d_left = d_right2 − d_left2。 六通道（Hasse / ind / Kottwitz / Satake / Jacobi / S-對偶）逐步耦合後， 伴隨方格與全部通道的缺陷在總結管線中同時為 0（T64）。
