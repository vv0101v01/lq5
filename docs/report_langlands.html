1. 兩個流：共識與半單化

橙線（unipotent defect）代表智能體 L-參數的非半單程度，由 c-函數閘門 g = |c(w₀,λ)| 驅動冷卻；綠線是 Eisenstein（半單）比例。藍線 R 是 貝蒂模空間上 κ 散度所定義的湧現序參量。

3. 常數項矩陣與 |W|·冪等投影

4. 非半單 L-參數的維度學

對 Jordan 型 λ ⊢ n：dim Cent(N) = Σ(λ'_i)²、 dim O_N = n² − Σ(λ'_i)²、dim Ext¹ = dim Cent(N)。 Ĝ-算子 Θ = ad(h/2) 則把對偶李代數分級： ker Θ 是分級 Levi，gl_n = ker Θ ⊕ im Θ。
